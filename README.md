# Agendador de Reels Instagram & Facebook

## Correção de Bucket no Supabase
O bucket padrão no código foi ajustado para `videos`. Você também pode definir o nome do Bucket diretamente na interface gráfica.

## Executar Interface Gráfica
```bash
python main_gui.py
```

## Gerar Executável (.exe)
```bash
pyinstaller --noconsole --onefile --name="AgendadorReelsMeta" main_gui.py
```
